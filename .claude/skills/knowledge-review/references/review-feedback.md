# Review Feedback Strategies

Guide for providing feedback during review sessions based on recall quality.

## Recall Quality Levels

### Level 1: 记住了 (Recalled Clearly)

The user's answer matches the reference answer with all key points.

**Response strategy:**
- Brief acknowledgment, no need to repeat the answer
- Optionally deepen: "你还可以从 X 角度理解这个概念"
- Optionally connect: "这和之前复习的 Y 卡片是同一个模型"
- Move on quickly, maintain session rhythm

**Example:**
> "对。补充一点：这个机制的底层动机其实是 [一句话]。下一题。"

### Level 2: 模糊 (Partial Recall)

The user got the direction right but missed key details, confused parts, or could not articulate clearly.

**Response strategy:**
1. First acknowledge what they got right
2. Point out the specific gap or confusion
3. Re-explain the concept focusing on the missed part
4. Connect to a concrete example or analogy
5. Offer to revisit the source Knowledge Unit

**Key teaching technique -- contrast:**
> "你说的是 A，但实际上区分的关键在于 [A vs B 的核心差异]。"

**Key teaching technique -- reframe:**
> "换个角度理解：不是 [用户的理解], 而是 [正确的本质]。"

### Level 3: 忘了 (No Recall)

The user has no memory of the concept or gives a completely wrong answer.

**Response strategy:**
1. Do NOT just show the answer. Teach from scratch.
2. Use the Thinking Pipeline approach:
   - **Problem**: "这个知识解决的问题是..."
   - **Essence**: "用一句话说就是..."
   - **Tradeoff**: "它牺牲了...换来了..."
   - **Transfer**: "同样的模式还出现在..."
3. Use concrete examples and scenarios
4. If available, fetch the linked Knowledge Unit for full context

**Example:**
> "没事，我们重新来。这个概念要从一个问题说起：[Problem]... 所以它的本质是 [Essence]... 它的代价是 [Tradeoff]... 你可能在 [Transfer] 里也见过这个模式。"

## Cross-Card Patterns

During a session, watch for patterns across cards:

- **Same model, different domains**: Point it out. "这道题和上一题其实是同一个 Feedback Control 模型。"
- **Prerequisites**: If the user forgot B because they never fully understood A, note it. "这道题的基础是 [A], 建议回去巩固。"
- **Contradictions**: If two cards seem contradictory, help resolve the tension. "这两道题看似矛盾，其实适用条件不同..."

## Session Pacing

- Aim for 2-3 minutes per card on average
- If a card takes longer because the user is learning (not recalling), that is fine -- but suggest continuing the deep dive outside the review session
- After 3 consecutive "忘了" cards, suggest pausing: "连续几个都不太熟，要不要先停下来逐个理解？"
