# 学习起点:后端工程师,算法与机器人零基础

学习者首次会话中明确披露的起点:
- 后端开发工程师,后端语言熟练
- 算法/数学基础薄弱(接近零),机器人领域零基础
- 目标:完整建立知识体系,最终独立实现工业级调度系统
- 场景兴趣广:仓储/工厂/港口 + 人形/具身
- 硬件只到架构层面

## 为什么这条记录重要(对未来会话的影响)
1. **后端类比是主教学手段** —— 几乎每个调度概念都要配后端类比,这是已确认的有效加速路径,不是可选点缀。已固化进课程样式(`.backend-analogy` 组件)。
2. **算法必须从零讲** —— 不假设会图论/最优化/控制论。L0-05 的数学前置课要认真上,不能跳。
3. **体系优先** —— 不能为"工作中要用"就跳过地基走速成路线。学习者明确说了"更想完整建立知识体系"。
4. **人形/具身是强需求** —— L4-02 必须重点设计,不能只是顺带提一句。
5. **L3 是学习者的主场** —— 工程化、架构、通信协议、容错这些课,学习者会感到熟悉,可以加速,把节省的时间补给 L2。

## 关于"已掌握"的诚实记录
首次会话只完成 L0-01 的知识讲解,学习者尚未演示出对任何调度概念的主动运用(自测题答案待回收)。因此在 glossary 里还没有任何术语被 promoted——这是诚实的状态,等自测或下一课互动确认理解后再补。
