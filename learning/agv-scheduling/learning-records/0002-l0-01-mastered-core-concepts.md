# L0-01 核心概念已掌握

学习者在 L0-01 课后自测中,对以下概念给出了正确或概念正确的回答,视为已扎根:

- **并发冲突**:正确识别为调度系统的核心问题(对应后端的并发写/热点 key)
- **吞吐量**:正确对应「单位时间完成任务数」
- **死锁**:答「交通死锁」——概念完全正确,且主动选了更精确的车辆场景表述。统一约定在本工作区简称「死锁」并标注与数据库死锁同源

## 一个被修正的认知(高价值)
学习者在「中间层叫什么」一题答「路径规划」,把**层里的一个子功能**当成了**整层的名字**。

修正后明确:
- 战术层 = **调度引擎 (Scheduling Engine)**
- 调度引擎内含三件事:任务分配 / 路径规划 / 冲突消解
- 「路径规划」是子功能,不是层名

这条修正价值在于:它恰好预告了 L2 的结构(三件事逐个学)。学习者的直觉其实摸到了骨架,只是缺一个正式命名。

## 对未来会话的影响
- L0-01 可标 ✅,术语表首批术语已 promoted
- 后端类比起作用了(学习者主动确认「类别很形象」),继续作为主教学手段
- 三层结构(战略/战术/执行)已建立,后续每课可引用「这在哪一层」来定位
