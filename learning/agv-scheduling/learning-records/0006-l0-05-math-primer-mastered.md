# L0-05 数学前置已掌握,L0 地基阶段全部通关

L0-05 课后自测 4/4 全对:边、代价、NP-hard、近似算法。学习者已掌握进入 L1 所需的最小数学语言。

## 已建立的数学认知
- **图**:节点 + 边 + 边权;有向边用于单向通道;邻接表 = 路由表/服务依赖 map
- **搜索**:图上找路的本质;BFS/DFS 是笨办法铺垫,Dijkstra/A* 是聪明办法
- **最优解 vs 可行解**:工业 99% 选可行解;「最好是好之敌」
- **复杂度**:O(n²) 是分水岭,指数级只对小规模可行
- **NP-hard**:多车调度是 NP-hard,无银弹;应对哲学(近似/启发式/分治/滚动/松弛)与后端工程智慧同构

## 算法短板的状态评估
学习者 L0-05 表现出对数学概念的快速吸收(4/4,无卡顿反馈)。后端类比在数学概念上依然有效(NP-hard≈缓存/最终一致等)。说明:
- 算法短板是「没学过」而非「学不会」,用直觉+后端映射的方式可以有效补
- L1 进入具体算法(Dijkstra/A*)时,要靠动手实现来验证是否真懂,不能只靠概念题
