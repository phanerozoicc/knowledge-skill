# L1-01 地图建模已掌握 + 一个关键澄清

## 掌握情况
L1-01 课后自测 4 题,3 题全对(节点、动态权重、邻接表)。学习者明确反馈"建图很顺利,经常做"——数据建模本就是后端工程师的强项,地图建模只是换了应用场景,L1-01 是学习者的舒适区。

## 一个必须当场纠正的概念混淆(高价值)
学习者把"工业全局规划用哪种地图"答成了**栅格**,正确答案是**拓扑**。

### 混淆点
学习者掌握了两种地图各自是什么,但**没分清它们的分工**:
- 全局规划(从A区到B区走哪几条主路)→ 用**拓扑图**(稀疏、快)
- 局部避障(在两节点间具体怎么绕障碍)→ 用**栅格图**(精细)

### 已用后端类比澄清
- 拓扑图 ≈ coarse routing table(粗粒度路由)
- 栅格图 ≈ per-packet 精细转发
- 工业实践 = 两者结合(先选大路,再走小步)

### 为什么重要
这个分工会直接影响 L1-02~L1-04 的理解:BFS/Dijkstra/A* 默认在拓扑图上做全局规划。如果学习者以为"全局用栅格",会对算法的规模和性能预期产生误判(在栅格上跑 A* 节点数爆炸)。

## 教学节奏调整
学习者数据建模能力扎实,L1-01 节奏可以加快。但 BFS/DFS(L1-02)是 Dijkstra/A* 的地基,且涉及学习者薄弱的算法实现,必须**亲手写过一次**,不能只靠概念。L1-02 会提供完整可跑代码,要求学习者实际运行并动手改。
