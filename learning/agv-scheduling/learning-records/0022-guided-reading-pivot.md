# 陪读模式确立:自读五站超 ZPD,L2-03 推迟

## 发生了什么
LAB-01 交付后,L2-03(MAPF 形式化)备课期间,学习者表示:"代码没有读太难看懂了。"——即还没开始读代码,并预判(正确)不读代码直接上形式化理论会很难。

## 解读(ZPD 校准)
- LAB-01 的五次散步按"自读 + 检查点"设计,实际超出当前 ZPD:对算法/数学短板的学习者,成体系的工业代码首读需要人在环,自读材料只适合当第二遍复习
- 学习者的直觉("先读代码再上理论")是对的:MAPF 形式化的每个符号都可以对应到代码实体,顺序颠倒两头都难
- 信号:连续反馈"吃力"两次(第一次要了地图,第二次要陪读)——脚手架要继续加细,不要加内容

## 对策
- **陪读模式**:每次会话只走半站(约 20 分钟内容),每段配 2~3 个低门槛检查点,答对再前进
- 节奏切分:上半场 = 跑 demo + models.py 资源身份三件套 + Reservation 逐字段;下半场 = ConflictType + Vehicle/Trajectory;然后 interval_index → reservation_table(心脏,预计拆两次)
- L2-03 暂停,代码读到 reservation_table 后再上(届时形式化的 G/agents/(s,g) 全部有实体对应)
- 教学工具:用 demo 真实输出做算术题(如 活跃预留=16 = V1 的 9 + V2 的 7),把"读代码"变成"能对账"
