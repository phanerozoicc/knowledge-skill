L1-05 · 运动学与轨迹:路径 ≠ 轨迹

阶段 L1 单机能力 难度:中等(概念) 前置:L1-04, L0-02 预计:45 分钟
🎯 这节课你将学会:理解为什么 A* 找出来的路径车开不了——因为车有运动学约束(不能原地直角拐弯、有转弯半径)。你会搞清楚两个常被混淆的概念「路径」vs「轨迹」,以及工业上怎么把 A* 的路径变成车真正能开的轨迹。这课把你 L0-02 学的底盘构型和 L1 的路径规划真正连起来,也是通向人形全身运动规划的关键伏笔。

核心区分:路径 ≠ 轨迹

这是整个运动规划领域最基础的一对概念,你必须分清:

路径 (Path)轨迹 (Trajectory)
是什么一系列几何位置的序列路径 + 时间信息(每个点在何时到达)
含什么"去哪"(x, y)"去哪 + 什么时候到 + 多快"(x, y, t, v)
考虑运动学吗通常不考虑(纯几何)必须考虑(要符合车的物理能力)
谁产出A*/Dijkstra(你的 L1-03/04)路径 + 速度规划 + 运动学平滑
后端类比API 调用顺序(逻辑链)API 调用 + 时间约束 + 限速
路径 vs 轨迹,就像:
  • 路径:你的服务调用链 = "订单服务→支付服务→库存服务"(只有逻辑顺序,没时间)
  • 轨迹:加上"支付必须在 3 秒内返回、库存查询限 100 QPS"——时间约束 + 能力约束
A* 给你的是"调用链"(路径),但车要的是"带时间和限速的执行计划"(轨迹)。中间差一道工序。

为什么车开不了直角:运动学约束

L0-02 你学过三种底盘构型。现在我们要把它们的运动学约束讲清楚——这直接决定了"路径能不能有直角"。

构型 1:差速驱动(Differential Drive)

两个轮子靠转速差转向。能原地旋转(一个轮正转、一个反转)。路径可以有直角。

构型 2:阿克曼(Ackermann,像汽车)

前轮转向,像汽车。不能原地转,有最小转弯半径 R。路径不能有直角,必须是平滑圆弧。

构型 3:全向(Omni,麦克纳姆轮/舵轮)

能横着走、斜着走,极致灵活。路径几乎任意,代价是轮子贵、载重有限。

怎么修:从路径到可执行轨迹

工业上的标准做法是两步走:A* 找粗路径,再用运动学曲线把它"圆滑"成车能开的轨迹。下面这张图是核心——把刚才那条带直角的路径,用 Dubins 曲线平滑:

三个原子动作:所有曲线的乐高积木

在讲三种曲线之前,先记住这个基础——任何受转弯半径约束的路径,都能拆成 3 种原子动作的拼接:

代号动作几何
SStraight直线
LLeft左转圆弧(半径=R)
RRight右转圆弧(半径=R)

记住 L/S/R 这三个字母——后面所有曲线,本质都是它们的组合。

三种曲线:本质区别在"车的能力"

DubinsReeds-SheppSpline
车能力只前进前进+倒车任意(差速/全向)
运动学严格?✅ 保证 R✅ 保证 R❌ 不保证
本质6 种 L/S/R 三段组合取最短Dubins + 倒车,组合变 ~48 种数学平滑(贝塞尔/B样条),不绑运动学
典型用户扫地车/部分 AGV叉车 AGV(要对位)差速/全向 AMR

Dubins 的实质(不是名字,是定理):Dubins 证明了,在最小转弯半径 R 约束下,从起点到终点的最短可行路径一定是 6 种组合之一——LSL、LSR、RSL、RSR、LRL、RLR(每种是 3 段 L/S/R 拼成)。所以 Dubins 不是神奇算法,是"有限种拼法取最短"。

Reeds-Shepp 的实质:同样思路,但因为允许倒车,每个动作有了方向(前进 L⁺/倒车 L⁻),组合从 6 种膨胀到约 48 种。叉车 AGV 用它——因为对位货架时经常要"前进-倒车-前进"微调,纯 Dubins 做不到。

Spline 的实质:和前两个不同——它是数学平滑工具(让曲线好看好走),不保证严格满足转弯半径 R。适合差速/全向车(它们本来就没严格 R 约束),或不在意严格的场景。

选择口诀:阿克曼只前进 → Dubins;阿克曼要倒车 → Reeds-Shepp;差速/全向 → Spline。

📌 这块和调度的关系(你真正该记住的)
  1. 调度层(拓扑)通常不管这些曲线——它产出节点序列,平滑在车载/局部规划器层。L3-03 的 VDA5050 协议就是证据:调度只下发节点/边序列,车辆自己决定怎么开过去。
  2. 但"路径 ≠ 轨迹"必须懂——否则你会设计出车开不了的调度方案。
  3. 做人形时,这一层会变成中央的核心——因为人形的"曲线"是几十个关节的全身运动规划,不能委托给车端。这就是 L4-02 的内容。
所以:做调度器,曲线是"知道概念";做人形调度,曲线是"核心能力"。完整细节见 运动学曲线速查。
📌 工业标准流水线
  1. A*(拓扑图)→ 得到节点序列(粗路径)
  2. 把节点序列转成几何折线(带坐标的路径)
  3. 用 Dubins/Reeds-Shepp/Spline 平滑 → 得到运动学可行的轨迹(通常在车载层)
  4. 加时间信息(速度规划)→ 最终可执行轨迹
你现在会的是第 1~2 步(A*),第 3~4 步是本课引入的概念。完整的单车规划 = A* + 平滑 + 速度规划。

人形伏笔(本课重点)

这课对人形特别重要,因为人形的运动学约束复杂到另一个量级:
  • AGV:运动学约束 = "转弯半径"(1~2 个参数)。Dubins 曲线搞定。
  • 人形:运动学约束 = 几十个关节的角度限制、速度限制、力矩限制、平衡约束。不能简单用一条曲线平滑。
所以人形的"从路径到轨迹"这一步,变成了一个专门的难题——全身运动规划(Whole-Body Motion Planning)。工具也从 Dubins/Spline 升级为:
  • 逆运动学(IK):算出"手要到这个位置,各关节该怎么弯"
  • 轨迹优化:把"平滑+不撞+平衡+省力"一起优化
  • RRT/L1-06:在高维关节空间里搜索
但核心思想不变:仍然是"路径(几何)→ 轨迹(满足约束的执行序列)"这个两段式框架。你学的"路径 ≠ 轨迹"的区分,在人形里完全适用,只是约束从"转弯半径"升级成了"全身关节"。这是 L4-02 人形调度的物理基础。

小结

  • 路径 ≠ 轨迹:路径是几何位置序列,轨迹是加了时间/速度/运动学约束的执行计划。
  • A* 给的是路径(数学最优),但车可能开不了——因为有运动学约束。
  • 底盘构型决定约束:差速(能原地转)、阿克曼(有转弯半径)、全向(几乎无约束)。
  • 工业流水线:A* → 几何折线 → Dubins/Reeds-Shepp/Spline 平滑 → 加时间 → 可执行轨迹。
  • 人形把这一步放大:运动学约束从"转弯半径"升级为"几十个关节",催生全身运动规划。但框架不变。
