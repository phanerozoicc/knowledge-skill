# 路线图:从零到工业级 AGV / 机器人调度系统

> 本文档是整个课程的骨架。每个**学习单元(Unit)**是一节课的体量(30~60 分钟可完成),单元被组织成 **6 个阶段(Level L0~L5)** 加一个横向 **硬件模块**。
>
> **阅读约定**
> - 每个单元标注:`【难度】` `【前置】` `【后端类比】`
> - `✅` = 已掌握(在 learning-records 有记录) `🚧` = 进行中 `⬜` = 未开始
> - 单元号格式 `L{阶段}-{序号}`,如 `L1-03`

## L1 — 单机能力:一台车怎么走

> 目的:先把**单台车**搞明白——它如何理解地图、如何规划路线、如何把路线变成实际运动。这是所有多机问题的基础(多机 = 多个单机 + 协调)。

### ✅ L1-01 地图建模  *(已掌握,见 LR-0007;澄清了栅格/拓扑分工)*
- **讲什么**:栅格地图 vs 拓扑图 vs 混合图;如何把仓库/工厂物理空间抽象成节点和边;边权(距离/时间/能耗);动态权重
- **【后端类比】**:建图 ≈ 给你的服务依赖建立数据模型;邻接表 ≈ 关注列表
- **【前置】**:L0-05
- **产出**:能把一张简单仓库平面图手画成一张图

### ✅ L1-02 搜索算法入门:BFS / DFS  *(已掌握,见 LR-0008)*
- **讲什么**:盲搜、广度/深度优先、为什么它们是起点但不够好(不最优、慢)
- **【后端类比】**:BFS ≈ 消息广播层层扩散;DFS ≈ 调用栈
- **【前置】**:L1-01, L0-05
- **产出**:手算一个小图的 BFS/DFS 顺序

### ✅ L1-03 Dijkstra 算法  *(已掌握,见 LR-0009;确立动手学习约定)*
- **讲什么**:带权图上的最短路、松弛操作、为什么能保证最优、复杂度
- **【后端类比】**:这就是网络路由协议(OSPF)的核心
- **【前置】**:L1-02
- **产出**:手算一个 6 节点图的最短路;理解"为什么 BFS 不行"

### ✅ L1-04 A* 算法  *(概念已掌握,见 LR-0010;动手练习待补)*
- **讲什么**:启发式搜索、f=g+h、可采纳启发式、A* vs Dijkstra 的取舍、工业实现细节(格子化、对角线、障碍膨胀)
- **【后端类比】**:A* ≈ 带业务直觉的搜索(先往目标方向探)
- **【前置】**:L1-03
- **产出**:在一个 10×10 网格上手算 A* 路径,并解释为什么走这条路

### ✅ L1-05 运动学与轨迹  *(概念已掌握,见 LR-0012;曲线深度已补足,新建 CURVES.md;待对账代码节点数)*
- **讲什么**:差速驱动 vs 阿克曼 vs 全向(麦克纳姆)的运动学约束;路径(几何)vs 轨迹(带时间);平滑(Spline/Dubins/Reeds-Shepp);为什么车不能原地直角拐弯
- **【后端类比】**:轨迹 ≈ 给 API 调用加上了时间约束和限速
- **【前置】**:L1-04
- **产出**:知道为什么"A* 找出的路车开不了",以及怎么修

### ✅ L1-06 RRT 与采样规划  *(已掌握,见 LR-0015;L1 阶段全部完成)*
- **讲什么**:什么时候图搜索失效(高维/连续空间)、RRT/RRT* 思想、与图搜索的互补关系
- **【前置】**:L1-04
- **产出**:知道面对机械臂/高维问题该换工具

## L2 — 多机调度核心:多台车怎么不撞不堵

> 目的:这是调度系统的**真正核心**。从"多车会撞"这个具体问题出发,讲清楚任务分配、冲突消解、死锁防护三件套。**这是从 L1 到工业级最关键的一跃。**

### ✅ L2-01 任务分配  *(已掌握,见 LR-0017;确认团队架构=带审核拍卖)*
- **讲什么**:任务→车的匹配问题;贪心/匈牙利算法/拍卖机制(CN);全局最优 vs 分布式协商的取舍
- **【后端类比】**:任务分配 ≈ 负载均衡器选实例
- **【前置】**:L1-04
- **产出**:能讲清三种分配策略的适用场景

### ✅ L2-02 冲突的本质与分类  *(已掌握,见 LR-0019;补全了时空轨迹计算方法)*
- **讲什么**:节点冲突 / 边冲突 / 跟随冲突 / 相向冲突 / 终点冲突;预留表(Reservation Table)概念;为什么"各自 A*"必然撞车
- **【后端类比】**:冲突 ≈ 并发写同一行;预留表 ≈ SELECT FOR UPDATE
- **【前置】**:L1-05, L0-04
- **产出**:能对着一个轨迹图标出所有冲突类型

### 🚧 LAB-01 代码导读:五次散步读下工业核心库  *(进行中,见 LR-0021;插入于 L2-02 与 L2-03 之间)*
- **讲什么**:工业代码阅读方法(先跑再读/先名词后动词/自底向上/测试当规格);按依赖顺序分 5 次散步导读 code/;一条预留的完整生命周期;四个正确性支柱各配一个亲手实验(含重现租约 bug)
- **【后端类比】**:单写者 = event loop;每车重拍快照 = read committed;sim = 测试替身
- **【前置】**:L2-02
- **产出**:能独立讲出 tick 流水线 + 预留的一生;综合挑战(真启发 _h、把现象写成第 37 个测试)通往 L2-04

### ⬜ L2-03 MAPF:多智能体路径查找(问题定义)
- **讲什么**:把"多车不撞"形式化为 MAPF 问题;代价函数(makespan / sum-of-costs);为什么 MAPF 是 NP-hard、意味着什么
- **【后端类比】**:NP-hard ≈ "没有银弹,只能启发式"的分布式难题
- **【前置】**:L2-02, L0-05
- **产出**:能用形式化语言描述一个 MAPF 实例

### ⬜ L2-04 冲突消解算法:从简单到工业
- **讲什么**:优先级规划(Prioritized Planning)→ 预留表(基于时间窗)→ **CBS(Conflict-Based Search)**(工业级核心);每种算法的最优性/完备性/复杂度
- **【后端类比】**:CBS ≈ 一个"乐观锁 + 冲突回滚重试"的调度器
- **【前置】**:L2-03, L1-04
- **产出**:在一个 2 车 5 节点例子上手算 CBS 一次完整迭代

### ⬜ L2-05 死锁防护与交通管制
- **讲什么**:多车死锁(环形等待)的形成;死锁四条件;banker 算法思想;单向化/缓冲区/信号量;路口交通管制(类似红绿灯)
- **【后端类比】**:这就是数据库死锁检测 + 分布式锁的翻版
- **【前置】**:L2-02, L0-04
- **产出**:能识别一个调度设计里的死锁隐患并给出修复

### ⬜ L2-06 端到端小实战:2~3 车仿真
- **讲什么**:把 L1+L2 串起来,在一个极简仿真(文字/伪代码级)里跑通"任务进来→分配→规划→避撞→执行"
- **【前置】**:L2-01~05, L1 全部
- **产出**:一个能跑通的最小调度器(伪代码或简化代码)

## L3 — 工程化与工业级:把算法变成生产系统

> 目的:学术算法 ≠ 生产系统。这一阶段讲"如何让一个能 demo 的调度器,变成 7×24 稳定跑、能水平扩展、能容错的工业系统"。**这一阶段最贴近你已有的后端经验。**

### ⬜ L3-01 调度引擎的软件架构
- **讲什么**:事件驱动 vs 周期轮询;状态机驱动的车辆管理;调度循环(tick);解耦:规划层 vs 执行层;单进程 vs 多服务
- **【后端类比】**:这就是设计一个高并发实时后端
- **【前置】**:L2 全部
- **产出**:画出工业级调度引擎的模块/线程/消息流图
- **💡 对接学习者**:增设「从集中式到混合式的演进路径」——学习者团队规划从集中式走向"车端自主规划+调度审核(请求式)",这正是后端「单体→微服务→云边协同」的翻版

### ⬜ L3-02 实时性与状态同步
- **讲什么**:硬实时 vs 软实时;位置同步频率与带宽;时间窗的动态更新;为什么"计划跟不上变化"以及如何滚动重规划
- **【后端类比】**:状态同步 ≈ 多副本一致性;滚动重规划 ≈ 增量计算/流处理
- **【前置】**:L3-01, L2-04
- **产出**:能设计一个"位置上报→重规划"的闭环

### ⬜ L3-03 通信协议:VDA5050 与车辆接入
- **讲什么**:为什么需要一个标准协议;**VDA5050**(AGV 行业事实标准)的核心对象(order/edge/node/instantAction)、MQTT vs REST、如何把异构车接入统一调度
- **【后端类比】**:VDA5050 ≈ 调度领域的 OpenAPI 规范 + 消息契约
- **【前置】**:L3-01
- **产出**:能读懂一段 VDA5050 的 JSON,知道怎么接入一辆新车

### ⬜ L3-04 故障容错与降级
- **讲什么**:车掉线/死车/电量耗尽/地图临时封锁的处理;心跳与超时;任务重分配;降级模式(单车自治 vs 全局接管)
- **【后端类比】**:这就是熔断、重试、补偿事务、最终一致性
- **【前置】**:L3-01, L2-01
- **产出**:一份"故障场景→系统行为"决策表

### ⬜ L3-05 可扩展性与性能
- **讲什么**:百车 vs 千车的瓶颈在哪;分层调度(区域/集群);增量重规划;并行规划;缓存与预计算
- **【后端类比】**:这就是分库分表 / 读写分离 / 水平扩展
- **【前置】**:L3-01, L2-04
- **产出**:能说出"从 100 车扩到 1000 车,调度器要改什么"

### ⬜ L3-06 可观测性、测试与上线
- **讲什么**:调度系统的监控指标(KPI 体系)、日志/轨迹回放、仿真测试(数字孪生)、灰度上线、A/B 策略对比
- **【后端类比】**:这就是 SRE 那一套
- **【前置】**:L3 全部
- **产出**:一份调度系统的上线 checklist

## L4 — 拓展领域:超越传统 AGV

> 目的:把视野从"轮式 AGV + 仓储"打开,讲清楚多机器人系统(MRS)、人形/具身机器人、群体智能的调度差异,让你建立的体系**可迁移**。

### ⬜ L4-01 多机器人系统(MRS)范式
- **讲什么**:集中式 vs 分布式 vs 混合式架构;协同 vs 自治的谱系;编队/集群任务;异构机器人协作
- **【后端类比】**:集中式≈单体;分布式≈微服务/P2P;混合式≈联邦学习式协调
- **【前置】**:L3-01
- **产出**:能判断一个场景该用哪种 MRS 架构

### ⬜ L4-02 人形 / 具身机器人调度 ⭐【核心必达】
- **讲什么**:为什么人形机器人调度比 AGV 难得多——自由度(几十个关节)、任务多样性(不止搬运)、人机混行安全、全身运动规划、长时任务编排;**如何把 AGV 调度能力迁移到人形场景**
- **【后端类比】**:从"调度车辆"升级到"调度技能编排的工作流引擎"(像 Temporal/Airflow)
- **【前置】**:L4-01, L1-06
- **产出**:能讲清 AGV 调度和人形调度的三处本质差异,并给出一份"AGV→人形调度迁移路线"
- **💡 说明**:学习者目前在做具身人形,这是全课程落地场景的核心,L1~L3 每处都已埋下通向本课的伏笔

### ⬜ L4-03 群体智能与涌现行为
- **讲什么**:Swarm / 涌现 / 去中心化协调的优势与陷阱;蚁群/Boids;什么时候分布式比集中式更好
- **【前置】**:L4-01
- **产出**:理解"为什么有时候不要中央调度"

### ⬜ L4-04 强化学习调度入门
- **讲什么**:为什么传统启发式有天花板;MARL(多智能体强化学习)调度;端到端 vs 混合;工业落地的现实障碍
- **【后端类比】**:RL ≈ 用"经验"代替"手写规则"的推荐/排序系统
- **【前置】**:L2 全部
- **产出**:能判断一个问题该用经典算法还是该试 RL

### ⬜ L4-05 仿真与数字孪生
- **讲什么**:为什么工业调度离不开仿真;典型仿真器(Gazebo/Ignition/自研);数字孪生的闭环;Sim2Real 的坑
- **【后端类比】**:仿真 ≈ 你写过的集成测试 + 影子流量
- **【前置】**:L3 全部
- **产出**:知道如何用仿真验证一个调度策略

> 目的:架构层面理解 AGV/机器人硬件,**不深入电路**。建议在 L1 开始前先看 HW-01 建立实物直觉,在 L3 时看 HW-02~05。每单元独立、可随时插入。

### ⬜ HW-02 导航方式与定位原理
- **讲什么**:磁条/色带/二维码/反射板/SLAM(激光/视觉)的原理、精度、成本、适用场景;为什么室内外不同
