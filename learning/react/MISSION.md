# Mission: 现代前端 / React(后端工程师的 AI 时代路线)

> 状态:2026-08-19 已确认动因(工作全栈交付 + 个人学习)、混合路线、按内容排课。详见学习记录 0002。

## Why
学习者是一名后端工程师(Java/Kotlin/Python,与 AGV 调度课同一人),学过 HTML/CSS/JS 但已陈旧。希望在 AI 时代以**正确的深度**掌握现代前端(React 为主):不是背语法和 API——那是 AI 的强项——而是达到**能独立交付完整功能、能验收和调试 AI 生成的前端代码**的深度。

学习动因(2026-08-19 确认):**工作全栈交付**(独立负责从接口到界面的完整功能)+ **个人学习兴趣**(体系化补齐前端)。

## Success looks like
- 能用 React + TypeScript 独立写出中等复杂度的界面(表单、列表、路由、与服务端交互),出问题时能定位到层(及格线)
- 能做前端架构决策——状态管理选型、组件拆分、Next.js vs Vite 取舍——并说出理由(职业线,**本课程主目标**)
- 能 review AI 生成的前端代码,识破常见坑:`useEffect` 依赖死循环、状态放错层级导致全树重渲染、服务端/客户端组件边界混乱
- 完成一个贯穿课程的实战项目并部署上线(选题**优先取自工作中的真实全栈功能**,个人 side project 备选)
- 能把课程里的判断讲给别人听(教学相长,也是验收手段)

## Constraints
- 后端经验丰富:闭包、缓存、流式传输、状态机、并发——这些直觉是最大资产,教学全程配后端类比(AGV 课已验证有效的手段)
- HTML/CSS/JS 有旧基础:不按零基础处理,但现代 JS(ES2015+)、TypeScript、npm 工具链水平**待诊断**(L0 进行)
- AI 时代定位:**目标「职业线」,不追「专家线」**——React 内部实现(fiber、调度器源码)、构建链内部原理不深入
- 前端是重技能学科:课程偏「看得见的产出」,每课有可运行/可交互的产出
- **按内容排课,不按时间**:下一课由「自测通过 + 动手完成」触发,不设每周课数(学习者 2026-08-19 明确要求)
- 动手学习约定沿用(AGV 课 L1-03 确立):学习者自己跑代码,系统负责提醒

## Out of scope(暂不深入)
- React 内部实现(fiber 算法、调度器源码)、构建工具链内部原理
- CSS 动画/视觉设计精通(够用即可,这正是 AI 擅长补的)
- 浏览器兼容性考古;旧技术栈(Class 组件为主的老代码)只求「能读懂」
- 非 React 生态的深度学习(Vue/Svelte/Solid 只做地图级了解)

## 整体路线图(L0→L4)
详见 `reference/ROADMAP.md`。一句话概览:
- **L0 地基**:前端全景与后端翻译、现代 JS 断代差、TypeScript 地基、工具链
- **L1 React 心智模型**:组件、状态、渲染模型、副作用——本课程最核心的一层
- **L2 工程化生态**:路由、服务端数据、状态管理选型、测试、样式方案
- **L3 架构与 AI 协作**:性能、Next.js 与 server-first、AI 结对工作流
- **L4 综合实战**:贯穿项目(优先工作真实全栈功能),从零到部署上线
