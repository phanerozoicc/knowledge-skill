## 学习者画像(沿用 + 本次会话新增)
- **身份**:后端工程师,Java / Kotlin / Python 熟练;当前工作:人形机器人方向

## 教学策略要点
- **后端类比是核心加速器**(AGV 课已验证):几乎每个前端概念配后端类比。已复用 `.backend-analogy` 样式组件
- **混合路线(默认,待确认)**:前几课打地基,尽快进入贯穿项目,体系作暗线——与 AGV 课的纯体系路线不同,因为前端是重技能学科,「看见像素」的反馈回路本身就是学习器
- **AI 时代定位贯穿全程**:目标「职业线」= 能架构 + 能 review AI 产出。每课的知识点尽量标注「这对应验收 AI 产出的哪块能力」
- **动手约定沿用**(AGV 课 L1-03 确立):「我来跑代码,但请提醒我」。每课显式标注动手任务;连续 2 课无动手反馈则温和催促;欠下的并入后续课而不是回头补
- **自我审查规范沿用**(AGV 课 L1-05 确立):每课/参考文档输出后,模拟挑剔读者(资深前端 + 后端架构师双视角)自查:概念表述过头?多义词消歧?后端类比失真?AI 时代的判断是否过时或无据?
- **教学风格**:详尽、体系、从浅入深;每课一个明确产出;测验选项尽量等长不给格式提示
