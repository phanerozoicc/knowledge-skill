## Knowledge

- [Official: react.dev](https://react.dev)
  React 官方文档,2023 重写后以「心智模型」为纲(Learn 教程 + Thinking in React)。Use for: 一切 React 核心概念的第一出处,L1 主源。
- [Official: MDN Web Docs(中文)](https://developer.mozilla.org/zh-CN/)
  浏览器与 Web 平台的权威参考。Use for: JS 语言特性、DOM、fetch、CSS 属性的事实核查。
- [Official: TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)
  TS 官方手册。Use for: L0 的 TS 地基、L2 的类型设计。
- [Survey: State of React 2025–2026 关键结论 — Strapi](https://strapi.io/blog/state-of-react-2025-key-takeaways)
  调查数据:RSC 新项目采用率约 45%,生态满意度与痛点。Use for: L2/L3 选型课的论据。
- [Guide: React Stack Patterns 2026 — patterns.dev](https://www.patterns.dev/react/react-2026/)
  2026 年 React 全栈图景:框架、构建、路由、状态管理、AI 集成。Use for: 生态地图课、选型对比表。
- [Article: What's Next for React in 2026 — Telerik](https://www.telerik.com/blogs/whats-next-react-2026)
  State of React 调查的第三方解读。Use for: 生态趋势的二重验证。
- [Official: Next.js Docs](https://nextjs.org/docs)
  server-first 路线的主框架文档。Use for: L3 的 App Router / RSC / Server Actions。
- [Essay: The Future of the AI Era for Developers(2026)](http://awongcm.io/blog/2026/01/04/the-future-of-the-ai-era-for-developers-what-2026-really-means-for-software-builders/)
  AI 时代开发者学习方式变化的判断。Use for: 课程「学习契约」部分的佐证。
