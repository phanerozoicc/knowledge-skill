# 学习起点:后端工程师,旧版前端基础,关心 AI 时代的正确深度

学习者首次会话(2026-08-18)明确披露:

- 后端工程师,Java/Kotlin/Python 熟练,与 AGV 调度课同一人。那边已验证有效的教学手段直接沿用:后端类比为核心加速器、偏好体系化从浅入深、动手任务需要显式提醒
- 学过 HTML/CSS/JS,但年代/深度未诊断——不按零基础,按「旧基础待更新」处理
- 核心关切不是速成,而是「AI 时代背景下学到何种程度」——首次会话已给出三层线回答(及格线/职业线/专家线),并以职业线为建议目标;学习者未表异议,但也**尚未确认**(提问后暂离,未作答)
