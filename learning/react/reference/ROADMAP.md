# React / 现代前端学习路线(L0→L4)

> 配套 `MISSION.md`。**混合路线**(2026-08-19 确认):地基(约 5 课)→ 尽快进入贯穿项目,体系作为暗线穿插。**按内容排课**:自测通过 + 动手完成才开下一课。
> 每阶段标注**【AI 侧重】**:这个阶段里 AI 能替你干什么、你必须自己会什么——这是本课程区别于传统前端课的主轴。
> 课数为估计,按诊断结果和学习节奏调整。

## L0 地基(预计 4–5 课)

| 课 | 主题 | 一句话 |
|---|---|---|
| L0-01 ✅ | 前端是什么:后端工程师的翻译课 | 全景 + 学习契约(学到哪一层) |
| L0-02 ✅ | 现代 JS 与你认识的 JS | ES2015+ 的断代差:模块、箭头函数、解构、Promise/async、闭包复习 |
| L0-03 | TypeScript 地基 | 类型即文档;后端人的主场(Java/Kotlin 直觉直接迁移) |
| L0-04 | 工具链:npm/pnpm、Vite | 为什么有「构建」这回事(类比:Maven/Gradle + 热部署) |

**【AI 侧重】** 语法与配置 AI 全包;但你要能读懂 `package.json`、报错栈、import 依赖图——否则连 AI 的产出怎么跑起来都不知道。

## L1 React 心智模型(预计 6–7 课)—— 本课程核心

| 课 | 主题 | 一句话 |
|---|---|---|
| L1-01 | 组件与 JSX | UI 的函数化:函数收 props,返回界面 |
| L1-02 | 渲染模型 | state 变了,React 怎么知道该重画(重渲染/协调/不可变性) |
| L1-03 | props、状态归属、状态提升 | 状态放哪,是前端版的「数据归属设计」 |
| L1-04 | 副作用与 useEffect | 最常见的坑所在地;什么时候不该用 |
| L1-05 | 列表、表单、受控组件 | 受控组件 ≈ 单一数据源原则在前端的形态 |
| L1-06 | hooks 规则与自定义 hook | 把逻辑抽成可复用的「协议」 |
| L1-07 | 阶段实战 | 把 L1 全部串起来的小项目(动手里程碑) |

**【AI 侧重】** 样板代码 AI 写;但「为什么这里多渲染了一次」「为什么 effect 死循环」AI 自己修不好——**心智模型就是你的调试器**。

## L2 工程化生态(预计 5–6 课)

| 课 | 主题 | 一句话 |
|---|---|---|
| L2-01 | 路由与页面组织 | URL 即状态 |
| L2-02 | 与服务端对话 | fetch、React Query/SWR、缓存策略(后端主场) |
| L2-03 | 状态管理选型 | 本地/服务端/URL 三分;何时才需要 Zustand/Redux |
| L2-04 | 样式方案地图 | CSS Modules / Tailwind / 组件库;够用即可 |
| L2-05 | 测试 | Vitest + Testing Library:「测行为,不测实现」 |

**【AI 侧重】** 选型对比材料 AI 给;**决策权和 review 是你的**——选错状态管理是 AI 无法替你背的架构债。

## L3 架构与 AI 协作(预计 4–5 课)

| 课 | 主题 | 一句话 |
|---|---|---|
| L3-01 | 性能 | 重渲染优化、code splitting;先测量再优化 |
| L3-02 | Next.js 与 server-first | RSC、Server Actions、缓存——React 19 主流方向,后端直觉直接升值 |
| L3-03 | AI 结对工作流 | spec 驱动开发、review AI 前端代码的 checklist、常见 AI 坑案例集 |
| L3-04 | 部署与可观测 | Vercel/自托管、错误边界、前端监控 |

**【AI 侧重】** 这一层的整体就是「AI 时代的新职业线」:AI 产出、你架构、你验收。

## L4 综合实战(贯穿项目;选题待动因确认)

- 从零到上线:需求 → 架构决策记录(ADR)→ AI 结对实现 → review → 部署
- 选题方向(动因已确认:工作全栈交付 + 个人学习):**优先取自工作中的真实全栈功能**;个人 side project 备选;机器人监控台(可与 AGV 调度课联动做调度大屏)若与工作契合仍是好选项
- 产出:一个部署在线上、能写进简历/工作汇报的项目

**【AI 侧重】** 模拟真实工作流:你是 tech lead,AI 是初级前端,你负责验收与架构。
